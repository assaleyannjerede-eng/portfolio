# Portfolio - Modèle de base

Ce dépôt contient un modèle de portfolio statique (HTML/CSS/JS) prêt à personnaliser.

Comment personnaliser :
1. Remplacez "Votre Nom" et le contenu textuel dans index.html.
2. Ajoutez vos images et captures d'écran dans un dossier `assets/`.
3. Mettez à jour les liens des projets et profils (GitHub, LinkedIn, etc.).

Déploiement rapide (GitHub Pages) :
1. Créez un repo sur GitHub et poussez ces fichiers.
2. Dans les paramètres du repo -> Pages, choisissez la branche `main` (ou `master`) et le dossier `/ (root)`.
3. Après quelques minutes, votre site sera disponible sous `https://<votre-utilisateur>.github.io/<nom-du-repo>/`.

Autres options :
- Utiliser Netlify ou Vercel pour déploiement continu (push automatique).
- Convertir en site Next.js / Gatsby / Hugo si vous voulez un CMS ou génération statique avancée.
