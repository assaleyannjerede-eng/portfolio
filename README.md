# Portfolio — Assale Jered Yann

Portfolio moderne et animé (HTML / CSS / JS).

## Contenu

- **index.html** — Structure principale
- **styles.css** — Design system + animations
- **script.js** — Typing effect, particules, reveal scroll, compteurs
- **CV_Assale_Ameliore.pdf** — CV professionnel amélioré
- **photocv.png** / **monforfait.png** / **logo.jpg** — Médias

## Fonctionnalités

- Fond animé (réseau de particules)
- Effet de typing sur les rôles
- Animations au scroll (reveal + barres de compétences)
- Compteurs animés
- Glow curseur
- Navigation mobile fluide
- Design dark moderne responsive

## Déploiement

1. Pousse sur GitHub
2. Active GitHub Pages (branche `main`, dossier `/`)
3. Ou déploie sur Netlify / Vercel (drag & drop du dossier)

## Personnalisation

- Liens GitHub / LinkedIn dans la section Contact
- Ajoute d'autres projets dans `#projects`
- Remplace les images si besoin
